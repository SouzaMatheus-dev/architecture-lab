# ADR-003 — Conteúdo versionado

Padrões vivem em `content/`, com catálogo, roteiro e exemplo .NET revisados por pull request. O identificador do padrão é o slug da URL.

Metadados e roteiros passam pelo schema do motor antes de chegar à página. Conteúdo inválido falha no carregamento e nos testes, em vez de aparecer incompleto para o aluno.
